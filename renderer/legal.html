02

隐私政策

本软件遵循本地优先（local-first）设计理念。核心原则是：你的代码和偏好只属于你，不因使用本软件而向作者或任何中心服务器上传。

2.1我们不收集什么

本软件不设服务器、不设账号体系、不采集遥测、不接入广告与行为分析 SDK。软件运行期间不会向作者或任何第三方发送你的以下信息：

  • 你的源代码、文件内容、目录结构；
  • 你的任务描述、对话记录、Agent 交互内容；
  • 你的本机路径、用户名、系统信息；
  • 使用时长、功能点击等任何行为数据。

2.2数据存储位置

你配置的数据仅保存在本机：

  • API 密钥：经本地加密后写入本机配置文件，仅用于向模型服务发起请求；
  • 记忆与规则：以 JSON / Markdown 格式保存在 ~/.cursor-local/ 与项目目录下；
  • 会话历史：保存在本地会话文件与工作区数据目录中；
  • 运行日志：仅保留在内存中用于本地排障，不含代码正文。

2.3模型请求的数据流向

当你主动发起 Agent 任务时，本软件会将完成该任务所必需的上下文（可能包含你用 @ 引用的文件片段、相关目录结构与你的任务描述）发送至你所配置的模型服务。该传输由你与该服务方直接发生，其数据处理受服务方隐私政策约束。请勿在涉密项目中配置会将内容上传至公网的服务。

2.4版本检查

当前版本不做自动联网检查。若未来加入更新检查功能，将以开关形式默认关闭，且仅传输版本号与平台标识，不含任何项目内容。

2.5你的控制权

你可以随时在设置中删除全部记忆与会话、清除 API 密钥，或直接删除软件目录。所有数据均由你在本机掌控，不存在作者侧副本需要申请删除。
