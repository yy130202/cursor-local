02

隐私政策

本软件遵循 local-first（本地优先） 设计理念。核心原则是：你的代码与偏好只属于你，不因使用本软件而向作者或任何中心服务器传输。本政策依据《通用数据保护条例》(GDPR)、《加州消费者隐私法》(CCPA/CPRA)及《中华人民共和国个人信息保护法》的透明性、目的限定与数据最小化原则起草。

2.1数据处理角色定位术语表

为避免误解，特此澄清本软件在数据保护法律下的角色：

角色说明
数据控制者你本人——你决定处理哪些数据、目的是什么、是否发送至第三方服务。
数据处理者本软件（作者）仅在你的设备上执行你指令的本地处理，不以自身目的处理数据。
独立第三方你配置的模型服务方，就传输给你的上下文，独立承担其数据处理责任。

2.2我们不收集什么（Data We Do Not Collect）

本软件不设服务器、不设账号体系、不采集遥测、不接入广告与行为分析 SDK。软件运行期间不会向作者或任何第三方传输：

  • 你的源代码、文件内容、目录结构与符号信息；
  • 你的任务描述、对话记录、智能体交互过程与生成输出；
  • 你的本机绝对路径、系统用户名、操作系统与硬件信息；
  • 使用时长、功能点击、崩溃日志等任何行为或统计数据；
  • 任何用于识别你个人身份的直接或间接标识符。

换言之，本软件的作者无法观测到你使用软件做了什么，因为你的一切都留在了你的机器上。

2.3数据存储位置与保留期限

你配置的数据仅保存在本机，存储位置与目的如下：

数据类别存储位置用途保留
API 密钥~/.cursor-local/（本地加密）向模型服务发起认证请求至你手动清除
模型与主题偏好~/.cursor-local/恢复你的界面与引擎设置至你手动清除
记忆与规则~/.cursor-local/*.json、*.md 及项目 .cursor-local/跨会话保持偏好与项目约束至你手动删除
会话历史工作区本地会话文件历史任务回溯与成果回滚至你手动清除
运行日志仅内存，用于本地排障错误诊断随应用退出销毁

2.4模型请求的数据流向（唯一出网路径）

当你主动发起智能体任务时，本软件会将完成任务所必需的最小上下文发送至你所配置的模型服务。该传输由你与该服务方直接发生，作者在此链路中不充当数据控制者或处理者。传输内容可能包括：

  • 你的任务描述与后续追问内容；
  • 你以 @ 显式引用的文件内容片段；
  • 智能体为理解问题而读取的相关文件与目录结构；
  • 你写入的记忆条目与项目规则。
请务必注意：若你配置的模型服务为公网服务，则上述内容将离开你的设备并受该服务方隐私政策约束。在涉密或受监管项目中，请配置私有部署模型，或改用本软件的 Ask / Plan 模式并审慎选择引用文件。

2.5敏感个人信息与特殊类别数据术语表

依据 GDPR 第 9 条，某些数据被归为敏感类别（健康、宗教信仰、种族、政治观点、生物识别等）。本软件不对此类数据作任何形式的收集、检测、识别或特殊处理，也不具备也不声称具备处理该等数据的能力。若你在任务中主动向智能体提供该等数据，其处理将适用 2.4 条规则，责任由你与所配置的服务方承担。

2.6自动化决策与 AI 处理说明

本软件的智能体基于大语言模型生成输出，属于 GDPR 第 22 条意义上的"自动化决策"范畴。请注意：

  • 智能体的输出为概率性生成结果，不构成对你的任何事实认定、法律判断或专业结论；
  • 本软件不建立用户画像、不做行为预测、不实施自动化决策干预；
  • 你应对任何影响你权益的 AI 输出进行人工复核，必要时寻求专业意见。

2.7本地存储与类 Cookie 机制

本软件不使用浏览器 Cookie，不投放追踪像素或跨站标识符。界面偏好（如主题色、背景不透明度、面板展开状态）通过 localStorage 保存在你的用户数据目录中，仅用于还原你的使用状态，不与任何外部服务共享。清除浏览器存储或删除软件数据目录即可完全清除。

2.8数据安全措施

  • API 密钥在本地存储时经加密处理（详见 modules/config.js），以降低明文泄露风险；
  • 所有数据文件位于你的用户数据目录或项目目录，访问权限继承操作系统账户权限；
  • 智能体执行文件操作时，默认受工作区边界校验与危险命令拦截保护（见 modules/agent.js）；
  • 本软件不实现网络传输层加密——因为它不进行网络传输。

请注意：操作系统层面的恶意软件、他人登录你的账户、物理接触你的设备等风险不在本软件控制范围内，请配合系统级安全措施（如 BitLocker、账户强密码）。

2.9数据泄露响应

由于本软件不收集数据，作者侧不存在"数据泄露"场景。若发生风险，应区分：

  • 你的设备被入侵：属你本机安全事件，请使用系统安全工具处置，必要时重装系统；
  • API 密钥泄露：立即前往模型服务方的控制台吊销（revoke）该密钥并生成新密钥；
  • 软件本身存在安全缺陷：欢迎通过开源仓库的 Security Advisory 私下报告（不公开 Issue），作者将在合理期限内评估修复。

2.10跨境数据传输

本软件自身不进行跨境数据传输。但若你配置的模型服务位于境外，则你的上下文将发生跨境传输。依据《个人信息保护法》第三十八条，此类传输须满足法定条件（如安全评估、认证或标准合同）。作为个人用户，你应自行评估并承担相应责任。

2.12你的数据权利

依据上述 GDPR、CCPA 及《个人信息保护法》所确立的查阅、复制、更正、删除、撤回同意、可携带等权利，你对本软件中的数据拥有完全自主的控制权，且无需向作者提出请求：
