02

隐私政策

本软件遵循 local-first（本地优先） 设计理念。核心原则是：你的代码与偏好只属于你，不因使用本软件而向作者或任何中心服务器传输。本政策依据《通用数据保护条例》(GDPR)、《加州消费者隐私法》(CCPA/CPRA)及《中华人民共和国个人信息保护法》的透明性与目的限定原则起草。

2.1我们不收集什么（Data We Do Not Collect）

本软件不设服务器、不设账号体系、不采集遥测、不接入广告与行为分析 SDK。软件运行期间不会向作者或任何第三方传输：

  • 你的源代码、文件内容、目录结构与符号信息；
  • 你的任务描述、对话记录、智能体交互过程与生成输出；
  • 你的本机绝对路径、系统用户名、操作系统与硬件信息；
  • 使用时长、功能点击、崩溃日志等任何行为或统计数据；
  • 任何用于识别你个人身份的直接或间接标识符。

换言之，本软件的作者无法观测到你使用软件做了什么，因为你的一切都留在了你的机器上。

2.2数据存储位置与保留期限

你配置的数据仅保存在本机，存储位置与目的如下：

数据类别存储位置用途保留
API 密钥~/.cursor-local/（本地加密）向模型服务发起认证请求至你手动清除
模型与主题偏好~/.cursor-local/恢复你的界面与引擎设置至你手动清除
记忆与规则~/.cursor-local/*.json、*.md 及项目 .cursor-local/跨会话保持偏好与项目约束至你手动删除

运行日志仅内存，用于本地排障错误诊断随应用退出销毁

2.3模型请求的数据流向（唯一出网路径）

当你主动发起智能体任务时，本软件会将完成任务所必需的最小上下文发送至你所配置的模型服务。该传输由你与该服务方直接发生，作者在此链路中不充当数据控制者或处理者。传输内容可能包括：

  • 你的任务描述与后续追问内容；
  • 你以 @ 显式引用的文件内容片段；
  • 智能体为理解问题而读取的相关文件与目录结构；
  • 你写入的记忆条目与项目规则。
请务必注意：若你配置的模型服务为公网服务，则上述内容将离开你的设备并受该服务方隐私政策约束。在涉密或受监管项目中，请配置私有部署模型，或改用本软件的 Ask / Plan 模式并审慎选择引用文件。

2.4本地存储与类 Cookie 机制

本软件不使用浏览器 Cookie，不投放追踪像素或跨站标识符。界面偏好（如主题色、背景不透明度、面板展开状态）通过浏览器 localStorage 保存在你的用户数据目录中，仅用于还原你的使用状态，不与任何外部服务共享。清除浏览器存储或删除软件数据目录即可完全清除。

2.5第三方组件

本软件集成的开源组件（含 Electron、Monaco Editor、xterm.js、Lucide Icons）均以库形式静态打包，不内置遥测，其行为受各自许可证与隐私声明约束。

2.6你的数据权利

依据上述 GDPR、CCPA 及《个人信息保护法》所确立的查阅、复制、更正、删除、撤回同意、可携带等权利，你对本软件中的数据拥有完全自主的控制权，且无需向作者提出请求：

  1. 查阅与复制：数据以明文 JSON / Markdown 存储于你指定的本地路径，可直接打开查看；
  2. 更正与删除：在设置页「记忆」「规则」中逐条删除，或直接删除对应文件；
  3. 撤回与清理 API Key：在设置页清除密钥字段，或删除整个配置目录；
  4. 可携带与销毁：复制本地文件即可迁移，删除本地文件即完成销毁——因作者侧不存在任何副本，无"忘记删除"风险。

2.7未成年人保护

本软件面向开发者与具备相应民事行为能力的用户，不主动面向未成年人收集任何信息。若未成年人需使用，应在监护人陪同与指导下进行。若你发现未成年人未经同意向我们（作者）提供了个人信息，请通过下方方式联系我们。

2.8政策更新与通知

本政策如有变更，将随软件版本发布并在开源仓库中留存历史版本。鉴于本软件不设账号与推送通道，我们不会主动向你发送通知；请在升级前查阅本文件的最新版本。

2.9联系我们

若你对自己的个人信息权利有任何疑问，或发现本软件存在安全问题，请通过开源仓库的 Issue 通道提出。出于隐私保护考虑，请勿在 Issue 中粘贴任何敏感代码、密钥或个人身份信息。
